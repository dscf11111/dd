## 분노 해소 사이트

사용자가 입력한 문장을 수정하지 않고 화면에서 파쇄 효과로 보여주는 Python 3.12 웹 앱입니다. 계정별로 원문 기록과 사용자가 고른 분노 단계가 저장되며, 공동 통계에는 한국 시간 기준 날짜별 글자 수와 파쇄 횟수만 합산됩니다.

### 기능

- 이메일과 비밀번호를 사용하는 계정 생성 및 로그인
- 문서 파쇄기, 블랙홀, 불태우기 모드
- 모드별 Web Audio 효과음과 음소거 설정
- 공동 파쇄량 온도계와 사용자 선택형 1~5단계 개인 온도계
- 기록 다시 보기, 개별·전체 기록 삭제, 계정 삭제
- 원문을 통계 데이터와 분리하여 저장

### 실행

외부 Python 패키지는 필요하지 않습니다. Python 3.12에서 실행합니다.

```bash
python3.12 server.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. SQLite 데이터베이스는 기본적으로 `data/anger.sqlite3`에 생성됩니다. 다른 위치를 사용하려면 `ANGER_APP_DB` 환경 변수를 지정할 수 있습니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

### 테스트

```bash
python3.12 -m unittest discover -s tests -v
```

### 배포 메모

GitHub Pages는 정적 파일만 제공하므로 이 앱의 Python API와 SQLite 데이터베이스를 실행할 수 없습니다. 공개 배포에는 HTTPS를 지원하는 Python 호스팅 환경과 영구 디스크가 필요합니다. 현재 포함된 `wsgiref` 실행 방식은 로컬 개발용이며, 인터넷에 직접 노출하지 마세요. 공개 서비스 전에 운영용 WSGI 서버, 로그인 요청 제한, 데이터베이스 백업·보호, 개인정보 보관 정책을 구성해야 합니다.

현재 저장소 버전은 비밀번호를 PBKDF2 해시로 저장하지만, SQLite의 원문 기록은 디스크에서 암호화되지 않습니다. 실제 개인 정보를 입력하는 공개 서비스로 사용하기 전에 저장소 암호화와 운영 환경의 접근 통제를 추가해야 합니다.
